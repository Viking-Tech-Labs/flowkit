# walkthrough

Nothing in this plugin yet; version 0.1.0 reserves the name. Build slice S3b puts here a skill that
takes a branch, a pull request number or URL, or a pasted diff, and walks you through testing the
change step by step. The change is read through whatever you have (your code host's CLI or a
paste); the claims to test are pasted, or fetched by your own tracker skill or MCP server; reading
a backend checkout is an optional configured path. Run history and friction notes go to a page in
your own brain vault.

Install, after adding the flowkit marketplace (see the root README): `claude plugin install walkthrough@flowkit`.
