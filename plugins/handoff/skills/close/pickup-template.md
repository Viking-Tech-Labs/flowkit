The pick-up block. The close writes it into the repo's pick-up doc under a heading of its own,
replacing the previous block, never appending a second one. Fill every line; write "none" rather
than dropping a line.

```
### WHERE TO PICK UP — <date "+%Y-%m-%d %H:%M">
Planned by: <this session's model>
Branch: <name> (<n> commits ahead of its upstream, pushed: yes/no)
Chain end: <the story's line, or none>
Landed this session: <one line per item>
Verified facts (do not re-derive): <paths, commands, numbers the next session would otherwise look up>
Decisions taken: <numbered; "(auto)" where taken unattended; where each is written down>
Not done / next: <ordered; the first item is what the next session starts on>
Needs you: <steps only the user can do: devices, consoles, secrets, approvals>
Known traps: <anything that cost time this session>
```
